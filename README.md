# Builder: Конструктор email-сообщения (C#)

Демонстрационный проект на C#, показывающий применение паттерна проектирования **Builder (Строитель / Конструктор)** на примере сборки email‑сообщения.

Идея: объект письма (`EmailMessage`) имеет много необязательных параметров (Cc/Bcc, html/text тело, заголовки, вложения), поэтому удобнее собирать его пошагово через билдера, а не через огромный конструктор.

## Что показывает пример

- Сборку **сложного объекта** по шагам (fluent‑API).
- Валидацию обязательных полей **в момент `Build()`**.
- Повторное использование билдера через `Reset()`.
- Опциональный слой **Director** (`EmailDirector`) для «типовых» писем.

## Где и почему здесь нужен Builder

`EmailMessage` — это пример объекта, который неудобно создавать через конструктор, потому что у него:

- есть **обязательные** части (`From`, минимум один `To`, `Subject`, тело письма),
- и много **необязательных** (Cc/Bcc, заголовки, вложения, HTML/текстовая версия).

Builder решает это так:

- конфигурирование идёт **пошагово** через методы (`From(...)`, `To(...)`, `Subject(...)`, ...),
- результат создаётся **один раз** вызовом `Build()`,
- проверка корректности выполняется централизованно в `Build()`.

Дополнительно:

- `Reset()` позволяет **переиспользовать** один и тот же экземпляр билдера для нескольких писем,
- `EmailDirector` показывает, как можно вынести «типовые рецепты» (например, письмо для сброса пароля), чтобы не повторять одинаковые цепочки вызовов.

## Структура

- `EmailMessage.cs`
  - `EmailMessage` — модель письма.
  - `EmailAttachment` — простая модель вложения.
- `EmailMessageBuilder.cs`
  - `EmailMessageBuilder` — билдер с цепочками вызовов.
- `EmailDirector.cs`
  - `EmailDirector` — готовые сценарии сборки (например, password reset).
- `Program.cs`
  - Демонстрация использования билдера и director.
- `BuilderEmailDemo.csproj`
  - Файл проекта.

## Как используется Builder в программе

Письмо собирается примерно так:

1. Задаём отправителя `From(...)`
2. Добавляем получателей `To(...)` (и при необходимости `Cc(...)`, `Bcc(...)`)
3. Задаём тему `Subject(...)`
4. Указываем тело `TextBody(...)` или `HtmlBody(...)`
5. (Опционально) добавляем заголовки `Header(...)` и вложения `Attach(...)`
6. Получаем готовый объект вызовом `Build()`
